# Aturan Proyek TokoKita

> Wajib dipatuhi setiap AI agent sebelum membaca, merancang, atau mengubah kode.

1. Baca [`CLAUDE.md`](../../CLAUDE.md) — bagian **Aturan keras** berlaku penuh
   untuk semua agent, bukan hanya Claude Code.
2. Baca [`docs/MULAI_DI_SINI.md`](../../docs/MULAI_DI_SINI.md) dan
   [`docs/PROJECT_STATUS.md`](../../docs/PROJECT_STATUS.md) untuk kondisi terkini.
3. PRD (`docs/PRD - E-Commerce.md`) adalah sumber kebenaran produk. Hal yang tidak
   dijawab PRD dicatat di `docs/OPEN_DECISIONS.md`, bukan ditebak.
4. Status verifikasi hanya `PASS`, `FAIL`, atau `NOT_RUN` (dengan alasan).
5. Tidak ada commit langsung ke `develop` atau `main`; semua lewat Pull Request
   ([`CONTRIBUTING.md`](../../CONTRIBUTING.md)).
